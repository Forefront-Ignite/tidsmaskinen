# UI/UX review — 2026-09-20

Investigation of every screen as shipped in v0.3.14, judged against the app's one job:
an accurate weekly report with the least manual attribution. Three independent code
audits (Report/My day/tray · Review/Discover/pickers · Calls/Customers/Settings/Debug)
plus live screenshots of each section. The designs for every proposed change are
published as an artifact: https://claude.ai/artifact/8eiZr7PGcYYocefW35fiYB

Line numbers refer to branch `claude/ui-ux-investigation-redesign-83d09c`.

## Verdict

- The Weekly Report and the Liquid Glass restyle hold up. The pain is upstream:
  attribution is spread over four surfaces (Review, Discover, My day popover, Calls
  sheet) with three scope vocabularies, and the default action is usually the one the
  user will have to repeat next week.
- Silent failures cost hours: a failed report load spins forever, the report's
  "Review unattributed" button lands in a different week, the tray never says when
  capture stopped, microphone permission is surfaced nowhere, and calls that bill in
  the report have no lane in My day.

## Research basis (added 2026-09-20)

Four parallel studies of shipping products were run against these designs. Three changed a
decision rather than confirming it. Sources are linked in the artifact.

- **Auto-capture time trackers** (Timing, Timely, RescueTime, ManicTime, Rize, Memtime, Toggl,
  Clockify, Harvest, TrackingTime, Qbserve). Nobody ships a one-at-a-time queue; Timing deleted
  its Review screen in favour of a filtered list. Every list product has multi-select. Rounding
  with "keep the day's true total" (ManicTime) and typed manual hours are universal, and this app
  has neither. Timely separates Hide from Delete; Toggl/Clockify/Timely lock a submitted week.
- **Keyboard triage** (Linear Triage, Superhuman, Hey, Gmail, Lightroom, Anki, Lunch Money, Monzo).
  List plus focused detail pane, never a card stack. `H` is defer and `E` is archive in the tools
  this user already uses; `S` is star. Linear arms no default so a reflex cannot confirm the wrong
  answer. Lunch Money's "apply to similar transactions" with a de-selectable preview is the bulk model.
- **macOS menu-bar health** (Little Snitch, Dropbox, Backblaze, Karabiner-Elements, Raycast, HIG).
  Verify functionally, never from a cached grant flag; Karabiner loops forever on macOS 26 for exactly
  that reason. Gate staleness behind a user threshold (Backblaze). macOS 26's "Allow in the Menu Bar"
  is a new failure mode outside Privacy & Security.
- **Rule management** (Little Snitch, Hazel, Apple Mail, Outlook, Xero, QuickBooks, Lunch Money, uBlock).
  No product shows a bare priority integer. Little Snitch computes precedence from specificity and flags
  shadowed rules at write time. Hazel previews what a rule matches before saving.

## Proposed changes (priority order)

### P1 — One attribution surface: Review absorbs Discover
Review gets a **Queue / All** switch. All = Discover's grouped list (repos, hosts, apps,
meetings, calls) with *Everything / Unattributed / Ignored* and a customer filter; rows
show the current attribution **and its scope**; attributed rows get *Change*. Range is
the week navigator (drop the rolling 7/14/30-day scope and its evaluate-rules-at-today
trap, `DateScope.swift:31`). Discover leaves the sidebar; "Sources" → "Attribution".
Why Review absorbs Discover and not the reverse: Review already models calls, host
groups, series and the shared backlog; deleting Discover as `liquid-glass-redesign.md`
states would lose Change, app rules, series week-scoping and the ignored-meetings list.

### P1 — Durable by default
- Series occurrence: a three-option control in Google Calendar's and Outlook's vocabulary —
  *Whole series* (default, bound to ↵) · *This and following* · *This meeting*
  (`TimelineView.swift:1508` today binds ↵ to "Save for this meeting"; scope defaults to `.justThis`
  at `:1217`). "This and following" is the case that matters when a client is reassigned mid-quarter.
- Signals: default scope *Always*; fixed order everywhere Always · This week · This day
  · Just this. Delete Review's private `AttrScope` (`ReviewView.swift:41`); use
  `AttributionScope`.
- Scope resets per Review card and is printed in the button ("Confirm · This week").
- Popover declares existing rules for the pattern before overwriting; undo/Clear of a
  window-bounded rule removes only that window (`ReviewView.swift:779` deletes every
  rule sharing the pattern).
- Shared-host guard: assigning `localhost`, Azure/Microsoft portals, or a host already
  assigned to another customer prompts to assign paths instead, pre-filled from the paths actually
  observed under that host.
- Both scope controls run broad → specific so the durable choice is always leftmost.
- The Confirm button states how much history the new rule rewrites ("also changes 14 items, 9.2 h").
  Timing, ManicTime and TrackingTime are all deliberately non-retroactive; being retroactive is better
  for a weekly report only if the rewrite is previewed and undoable.
Evidence: Customers → Adzcut shows `planner.cloud.microsoft` ×8 and `portal.azure.com`
×5 as stacked week-bounded rules.

### P1 — Triage that removes repeat work
Per-day hours strip; the three longest sessions with titles/paths linking into My day; suggestions on
`1`–`3` with last week's answer first, never on Return, and Confirm disabled until a target is picked;
keyboard `↵` confirm, **`H` skip, `E` ignore** (not S/I — S is star in Gmail, Superhuman and Linear),
`J`/`K` move, `/` search, `⌘K` palette, `?` shortcuts; multi-step `⌘Z` whose toast names the rule it
wrote and how many past items moved; "apply to similar" after a confirm with a de-selectable list;
Skip has a stated destination (back at the end of the pass) and Ignore asks occurrence-or-source;
progress in hours with the under-5-min hidden count visible; three end states (all attributed /
nothing recorded / calendar stale); report CTA passes `reviewTargetWeekStart`
(`WeeklyReportView.swift:169, 482` don't); next-week disabled past today; host groups drop
"Assign host" and get a path checklist with one Confirm.

### P2 — My day: grouped agenda and a Calls lane
Add a calls track to `TimelineBlock.Track`; group agenda rows by repo/app/channel for the
day with "Attribute all N"; day stats become active / attributed / open (same math as
the report's day column) instead of "sources · tracks"; foreground lane on by default,
lanes menu replaces the icon toggles; ⌘←/⌘→/⌘T for days; stable id for the in-progress
foreground block (`TimelineBlocks.swift:246` changes it every sample, tearing down the
popover); ignored repos render dimmed rather than vanishing. Calls tab stays as the
audit log; gains an Unattributed filter and inline Attribute/Ignore.

### P2 — Weekly report
**Rounding** (Nearest / Up / Down, quarter-hour default, ManicTime's "keep the day's true total",
Timing's hover-to-see-raw) — the largest single gap against the category. **Per-day open counts** in the
weekday headers linking into Review scoped to that day (Timely's per-day unlogged count).
**Manual entry** for hours capture never saw — a missing concept, not a missing control; every product
in the category accepts typed hours. **A reported-week marker**, so a late calendar sync cannot silently
change a number already filed. Plus: render `loadError` with Retry (`WeeklyReportView.swift:13, 720`);
stale-calendar/hooks banner; "Week 38 · through today" instead of "TRACKED THIS WEEK"; delta only as
same-weekday like-for-like; one table with collapsible customer rows, an
"Unattributed → Review" row (replaces both the hero backlog card and the dashed row),
no zero-hour customers; cell → day in My day, row hover → contributors (`Breakdown`
is computed today and unused); drop the customer rows + sparklines section; ⇧⌘C for the
export (⌘C stays text copy); TSV header with year and "Customer · Project".

### P2 — Menu bar popover
Health stripe of six fixed badges carrying their own status colour (Accessibility, Chrome, Microphone,
Calendar last sync, Hooks, Menu-bar visibility) with one-click fixes. Verify **functionally**, never from
a cached grant: poll `AXIsProcessTrusted()`, probe Automation with a real Apple event and catch error
-1743, read microphone status from AVFoundation. The tray icon is a secondary channel only (template
images cannot carry colour, and macOS 26 can hide the icon entirely). One notification for Accessibility
or Automation loss; calendar staleness waits behind a user-set threshold. Plus: "Now" card showing what is being recorded and where it
lands, with "Not this?"; render `state.lastError`; one Review entry; drop "· N
samples"; badge on the tray icon when a source is broken.

### P3 — Customers rules and Settings
Customers: source as section headers instead of a CC chip on all 23 rows; **the priority integer leaves
the interface** (no surveyed product shows one — show the consequence, "3 repos match · always · most
specific wins"); a stack of week-bounded rules is drawn as a **week strip** coloured by target rather than
an "8 rules ⌄" disclosure; conflicts are **flagged at write time**, not described in a later audit
(Little Snitch); a live **match count** while editing ("62 samples in the last 90 days", Hazel);
real in-place Edit instead of delete-and-recreate; "Make permanent" previews exactly what it overwrites
before committing (Lunch Money); shared hosts flagged with "Assign paths…" pre-filled from observed paths. Settings: new **Setup** pane with seven live-verified steps (Accessibility, Chrome automation,
microphone, Microsoft sign-in, hooks, **menu-bar visibility** — a macOS 26 failure mode outside
Privacy & Security — and customers), shown first while anything is red and kept in the rail afterwards
so it stays findable; every System Settings deep link falls back to opening Settings plain because the
`x-apple.systempreferences:` scheme is undocumented and some panes broke in macOS 26; Debug moves to an **Advanced** pane at the bottom of the rail; remove the static
"Attribution" text in Tracking (`SettingsView.swift:268`).

## Cut list
The Queue/All mode switch · the `S` and `I` shortcuts · the rule priority integer ·
"8 rules ⌄" as a disclosure · Discover (after list mode) · report customer rows/sparklines · hero backlog card +
dashed Uncategorized row (merge into the grid) · "+8.0h vs last week" unless
like-for-like · "sources/tracks" day stats · "· N samples" · CC chip on every row ·
Settings › Tracking › Attribution text · Review's `AttrScope` · `SearchableEntityPicker`
(`CustomerProjectPicker` covers the filter; `AddRuleSheet` needs one flag) · the
second Review control in the tray · "Assign host" on host-group cards.

## Missing list
Rounding in the report · manual time entry · a reported-week marker · bulk assignment and
"apply to similar" · capture health (tray, Setup pane, tray badge; mic permission is checked nowhere) ·
calls lane in My day · evidence on the Review card · keyboard for confirm/skip/ignore/
weeks/days/copy · rule editing and de-duplication · error and stale states · report
drill-down · a learnable rule kind for Teams/Zoom 1:1s (or an honest "not supported"
in the call sheet).

## Suggested order of work
1. Defaults and scope (small diffs, largest effect).
2. Review card v2 + report→Review deep link + render report errors.
3. Review list mode; remove Discover and the rolling scope.
4. Calls lane, grouped agenda, stable live-block id.
5. Tray health + Setup pane + mic permission; Debug → Advanced.
6. Report compaction and Customers rule hygiene.
